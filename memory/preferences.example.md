# Preferences (example: copy to `preferences.md` and edit)

How I want the agent to work. One rule per line, each with the reason ("why") so it can be applied with judgement.

- Ask one short question when something is ambiguous instead of guessing, because a wrong guess costs more than a question.
- Small commits with conventional messages, no push, because I review and push myself.
- Report real results: if a test fails, say so with the output.
- Keep answers short but complete: the result, the data I need, the next decision.
- Decide alone when the context allows it. Always ask before anything that can break something, change a project's state or involve other people.
